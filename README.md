# Lab Activity 1: Discussion
I integrated the Image widget into the newsfeed_card.dart
to display a picture in a post. I used Image.asset to load
the image from the assets folder. I also used a condition
to check if the imageAsset is not null. If the post has an
image, it will display the picture. If there is no image,
the picture will not appear. This makes the newsfeed more
flexible because posts can have different content.
